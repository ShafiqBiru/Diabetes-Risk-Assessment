# 🩺 AI Diabetes Risk Assessment

**Rocheston RCAI Classroom Project** — Machine learning-powered diabetes screening tool.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)

## Features

- **Risk Assessment**: Enter clinical parameters and get an AI-assisted diabetes risk estimate with probability scores
- **Data Explorer**: Interactive EDA with histograms, correlation heatmaps, and summary statistics
- **Model Analytics**: Benchmark comparisons across Random Forest, KNN, Logistic Regression, and Decision Tree

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dataset

Pima Indians Diabetes Dataset (768 records, 8 clinical features + 1 target).

## Tech Stack

Python · Streamlit · Scikit-Learn · Pandas · Matplotlib · Seaborn
